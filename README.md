Разрабатываю <a href="https://neurosquad.ai/" target="_blank"><b>NeuroSquad</b></a> — десктопное приложение для Windows и macOS, в котором CLI-агенты для кода (Claude Code, Codex, Antigravity, OpenCode и другие — всего 22) работают живыми терминальными карточками на одном холсте.

- Зовёт, когда агент ждёт вас: точный статус из хуков самих CLI, вопрос агента прямо в уведомлении, ответить можно с телефона.
- Разные CLI и модели вперемешку, точная стоимость по каждому агенту.
- Команды агентов, связанных стрелками.
