I'm building <a href="https://neurosquad.ai/" target="_blank"><b>NeuroSquad</b></a> — a desktop app for Windows and macOS where AI coding-agent CLIs (Claude Code, Codex, Antigravity, OpenCode and more — 22 in total) run as live terminal cards on one canvas.

- It calls you when an agent is waiting: exact status from the CLIs' own hooks, the agent's question right in the notification, and you can answer from your phone.
- Mix CLIs and models freely, with the exact cost of every agent.
- Squads of agents connected by arrows.
